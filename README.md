# Matrixgrad
This is my implementation of a deep learning engine written from scratch in python, for now it is a reverse-mode autodiff framework for matrices that supports MLP's if the user correctly sets the matrix shapes. It expands on the idea of micrograd from Andrej Karpathy by introducing matrices instead of scalar values. The goal is to have it eventually work like an actual deep learning library and support operations such as convolution/batchnorm/attention etc, all while only using numpy.
